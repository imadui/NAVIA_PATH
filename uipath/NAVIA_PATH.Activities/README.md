# NAVIA_PATH.Activities

UiPath activity library for **NAVIA PATH**.

## Manage Packages: self-contained runtime

The published library is designed for users who install it directly from **UiPath Manage Packages**. No Python installation or `.venv` is required on the runtime machine.

The package contains a safe `Runtime` payload generated by the NAVIA PATH build:

- the compiled `NAVIA_PATH_vX.Y.Z.exe`;
- `CURRENT_VERSION.txt`;
- public `config/config.json`;
- provider `.env.*.example` templates only.

The package never contains active credentials, active `.env.<provider>` files, ADC files, or a `Secrets` directory.

At the beginning of **NAVIA PATH Edge** or **NAVIA PATH Chrome**, the workflow automatically:

1. resolves an explicit `in_NavIAPathExe` / environment override when provided;
2. otherwise finds the Runtime embedded in the exact installed NuGet package version;
3. installs or updates that executable under `%LOCALAPPDATA%\NAVIA_PATH`;
4. preserves the user's existing `config.json` and active provider credentials/configuration;
5. creates or refreshes `%LOCALAPPDATA%\NAVIA_PATH\NAVIA_PATH.exe`;
6. runs the canonical NAVIA PATH check before browser automation:
   - Edge: `NAVIA_PATH.exe --check --browser msedge --json`
   - Chrome: `NAVIA_PATH.exe --check --browser chrome --json`
7. stops immediately with the check details if provider authentication or the required browser is not ready.

## Provider configuration

Provider selection remains generic and model-agnostic. NAVIA PATH auto-detects the provider from `NAVIA_PROVIDER` or `config/config.json`.

Provider `.env.<provider>` files are optional convenience files. Users may instead use system/process environment variables, provider-native credentials, Google ADC for Vertex AI, or other supported credential mechanisms.

Supported providers include Vertex AI, Gemini Direct API, OpenAI, Anthropic and Azure OpenAI.
