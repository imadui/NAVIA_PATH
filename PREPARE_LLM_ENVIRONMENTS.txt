================================================================================
 NAVIA PATH - LLM Provider Configuration Reference
================================================================================

README.md is the source of truth for installation and first use.
This file is a compact provider-variable reference only.

Primary workflow:
  1. Copy one provider .example file to the matching active .env file.
  2. Fill in your provider-specific settings/credentials.
  3. Run CHECK_ENVIRONMENT.cmd -Provider <provider>.
  4. Verify %LOCALAPPDATA%\NAVIA_PATH\NAVIA_PATH.exe.
  5. Execute NAVIA or use the UiPath Library.

Do not commit active .env files or credentials.

================================================================================
 1. GOOGLE VERTEX AI
================================================================================

Template:
  config\providers\.env.vertex.example

Active file:
  config\providers\.env.vertex

Variables:
  NAVIA_PROVIDER=vertex
  NAVIA_VERTEX_PROJECT=<your-project>
  NAVIA_VERTEX_LOCATION=global
  NAVIA_VERTEX_MODEL=gemini-3.8-flash
  NAVIA_VERTEX_TIMEOUT_SECONDS=60
  GOOGLE_APPLICATION_CREDENTIALS=credentials\vertex_credentials.json

Portable credential:
  credentials\vertex_credentials.json

Alternative ADC:
  %APPDATA%\gcloud\application_default_credentials.json

Prepare:
  CHECK_ENVIRONMENT.cmd -Provider vertex

================================================================================
 EXECUTION
================================================================================

After successful preparation, use the installed local runtime:

  %LOCALAPPDATA%\NAVIA_PATH\NAVIA_PATH.exe

Example PowerShell:

  & "$env:LOCALAPPDATA\NAVIA_PATH\NAVIA_PATH.exe" run --browser msedge --prompt "Open https://example.com and tell me the page title"

For Windows Mark-of-the-Web, runtime verification, UiPath integration and
troubleshooting, follow README.md.
